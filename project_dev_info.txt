UNDERSTANDINGS:

contoller methods are not called by you but are called by spring boot when that particular annotation/mapping is been hit.
Flow is Client sends post request to controller - it controller stores the request details as DTO(Data Transfer Object) of SignupRequest
This DTO is validated and if passed then sets the values.
controller then calls the server layer method saveUser() which creates a new user sets it's required params using DTO and 
then saves it to DB using repository.

NEVER USE DTO Directly to store details in DB - cause it leads to tight coupling if we want to add new fields to User/DTO in future then it might fail and crash the app 

throw is used to throw exception manually and used inside method or block of code. Can throw only 1 exception at a time.

throws is used in method declaration and indicates that method can throw 1 or more exception and tell caller of method 
to handle the exception.
